# @marklyra/editor-runtime

通过独立 origin 的运行页面提供浏览器编辑器实例。宿主负责文件访问、编码、原生窗口与实际持久化。

```ts
import { MarkLyraEditor } from '@marklyra/editor-runtime';

const editor = new MarkLyraEditor(container, {
  runtimeUrl: 'http://127.0.0.1:4174/index.html',
  markdown: '# MarkLyra\n',
});
await editor.ready;
const source = await editor.flush();
// 在宿主成功保存 source 后，再调用 await editor.markSaved(source)。
editor.destroy();
```

通过 `load` 切换文稿，`execute` 执行类型化命令。`getMarkdown` 是缓存，不能替代保存前的 `flush`；同步失败时保留当前文稿并报告错误。React 适配位于 `@marklyra/editor-react`，不得逐次输入重建实例。详细接口以导出的 TypeScript 声明为准。

编辑器引擎与页面直接维护在本包的 `src/engine`、`src/page`，样式、字体和语言包位于 `assets`，随附库位于 `vendor`。主题由 `@marklyra/editor-themes` 管理，桌面设置页由应用管理。运行页面生成到本包的 `dist/page` 并随包归档；桌面构建消费同一运行页面，不依赖仓库外输入。自有代码统一采用根 `LICENSE` 的 Apache-2.0，根 `THIRD-PARTY-NOTICES.txt` 随运行页直接附带。

## Markdown 表格交互

所见即所得模式下，悬停 Markdown 表格单元格时显示与当前行等高、列等宽的扁条手柄；悬停末行、末列时提供沿表格边缘的快速追加条。单元格与手柄之间的过渡区域保持可用，避免慢速移入时闪退。行列菜单支持前后插入、相邻移动、删除行列和删除表格，可以在菜单顶部切换操作范围。旧的尺寸、对齐、删除工具栏隐藏，统一由新菜单提供入口；尺寸通过插入、删除行列调整。原有右键菜单和 Tab 导航继续保留。

鼠标打开紧凑菜单时不预选任何命令。光标在单元格中时，`Alt+Shift+T` 打开行操作菜单；方向键、Home/End 选择操作，左右方向键切换行列。在“对齐方式”项上按右方向键进入子菜单，左方向键或 Escape 返回上一级；主菜单中 Escape 关闭并返回原光标。只有键盘导航显示细线焦点提示。表头不能直接删除，最后一列不能删除；这些限制与现有命令一致。

手柄由 `editor-runtime` 内部管理，各宿主和 React 适配层无需重复实现。界面位于编辑内容之外，悬停不修改选区或文稿。菜单绑定具体单元格、文档代次和版本，执行前再次校验，并复用右键菜单的源码保护、命令及撤销链路。输入法组合输入、只读、源码模式和文档切换期间不提供可执行的手柄。

左／中／右对齐位于列菜单的“对齐方式”侧边子菜单，通过 Markdown 分隔行的冒号表达，作用于整列。“设为标题行／列”将对应非空单元格的内容加粗，不改变行列顺序、表头结构或单元格类型。已有加粗保持不变；一次整行／整列格式操作对应一次撤销。格式修改逐一核对单元格身份和文本，仅替换已验证的内容范围，保留其他单元格、分隔行、原有边距及换行。

本轮只支持 Markdown 可表达的操作，不引入合并、颜色、逐单元格对齐或 HTML 降级，也不移植排序、批量清空和复制行列。无法验证源码结构的表格不提供新菜单。狭窄区域可从行菜单切换到列操作，或使用键盘入口。

## 图片预览

所见即所得图片上悬停时提供“查看大图”线框按钮，右键菜单也提供相同入口。预览为宿主文档中的独立模态层，跟随明暗主题；支持适应窗口、适应宽度、100%、缩放、拖动平移、90° 旋转及重置。滚轮浏览长图，Ctrl/⌘＋滚轮或触控板捏合缩放；`+` / `-` 缩放，`0` 适应窗口，`1` 原始尺寸，`R` 旋转，Esc 或关闭按钮退出。Tab 在预览控件内循环。

所有变换只作用于预览图像，不改变正文图片尺寸、源码、资源文件或编辑器撤销历史。入口位于编辑内容之外；加载占位、输入法组合输入及源码模式下不提供入口。关闭时仅在文档与图像身份仍匹配时恢复编辑焦点、选区及滚动位置，切换文档和销毁实例会撤销预览。预览复用已解析的授权显示 URL，不另行读取图片路径或下载资源。

`onImagePreviewChange(open)` 通知宿主暂时屏蔽后台编辑命令及原生标题栏附件；React 适配层会转发该回调。原生宿主可通过 `imagePreviewTopInset: () => number` 为窗口控制保留顶部空间（CSS 像素）。`editor.isImagePreviewOpen` 可同步查询状态，`editor.closeImagePreview(restore?)` 主动关闭，`restore` 默认 true。预览期间 `focus()` 聚焦查看区域，内容命令会拒绝执行；`load()` 会先关闭预览再加载新文稿。宿主 CSP 需要允许自己的图片资源 URL，MarkLyra 桌面端只为窗口内授权的 `__images/` 资源路径增加显示许可。

### Mermaid 图预览

已完成渲染的 Mermaid SVG 图使用同一个悬浮入口与预览窗口，支持缩放、平移、适应窗口／宽度、旋转和 Esc 关闭。点击图表本身仍展开原有源码编辑器；源码展开时入口避让代码语言控件。`onImagePreviewChange` 和 `isImagePreviewOpen` 同样涵盖图表预览，宿主无需维护第二套模态状态。

仅在点击入口时复制当前 SVG，并将当前计算样式固化到脱离正文的副本。预览不重新执行 Mermaid、不改动图表模型、原 SVG、Markdown 源码或撤销历史。副本保留本地箭头与裁剪引用，剔除可执行元素、事件属性和外部资源引用；尺寸与内容大小受限。源码正在重绘、渲染错误或输入法组合输入期间不开放旧图预览；同源码的 SVG 重绘可继续查看既有快照，文稿或图表源码变化则撤销预览。
