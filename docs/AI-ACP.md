# MarkLyra ACP 文档助手

## 设计与边界

AI 入口位于标题栏现有目录/侧栏图标旁。目录与 AI 复用右侧面板、收展动画和宽度控制，各自保留宽度；切换和隐藏不会重建编辑器或丢弃正在进行的对话。目录和 AI 共用的第三栏使用浅色实线圆角框：在原生覆盖式标题栏下方留出 32px 顶部位置，普通/全屏布局留 6px 间距，底部保留 6px；拖动手柄只覆盖面板高度，不再绘制触顶竖线。AI 会话历史和设置按钮沿用新建按钮的细边框。AI 页面沿用 Shell 的主题变量。设置导航提供“智能体”，管理界面由可信 Shell 渲染；隔离设置 iframe 只发送布尔导航消息，不接触安装命令、凭据或 ACP 连接。

实现分为三层：

- `features/ai`：会话状态机、流式展示、上下文、权限交互和历史 UI。
- `src-tauri/src/agents`：受管安装、stdio JSON-RPC、窗口/工作区能力、凭据、持久记录、MCP 文档工具和登录 PTY。
- 现有 `DocumentService` / `WindowServices`：文档编码、保存前比较、跨窗口写入串行化与外部变更通知。编辑器 core/markdown 不引入原生或 React 依赖。

ACP 是编辑器与智能体之间的协议，不是操作系统沙箱。本机智能体仍以当前用户身份运行，可能使用自己的文件、命令、插件和权限策略。MarkLyra 严格限制自身提供的文件工具与 IPC；不能把此限制描述为对第三方进程的操作系统隔离。设置页明确说明这一点。协议能力按初始化结果协商，不假定所有智能体支持同样的登录、会话恢复、配置或模式。

协议依据：[ACP v1 初始化](https://agentclientprotocol.com/protocol/v1/initialization)、[Prompt Turn](https://agentclientprotocol.com/protocol/v1/prompt-turn)。

## 待处理提醒

需要授权或补充信息时，文档区域右上方显示“AI 等待处理”及当前窗口的待处理数量。提示不会展开面板或移动编辑焦点；点击后展开对应 AI 会话，定位并聚焦授权卡片，批准与拒绝仍需明确操作。

“设置 → 智能体 → AI 等待授权时提醒我”默认开启并跨启动保存。关闭只停用系统动画，应用内标记仍保留。Windows 后台窗口使用任务栏短暂闪烁，macOS 使用信息级 Dock 跳动；不激活或置顶窗口，不播放应用提示音。系统设置可能影响动画呈现。

Rust 宿主在接收已验证的 ACP 授权、写入、终端创建、补充信息请求及 MCP 文档操作请求时登记提醒，因此后台 WebView 降频不影响原生触发。可信 Shell 同步交互队列；宿主再次核对窗口、连接、活动任务和未结束请求，不接收任意窗口标识或命令内容作为提醒授权。同一请求只提醒一次，同一窗口同批待处理请求合并提醒；回到窗口、处理请求、取消任务、结束连接或关闭窗口会清理动画，旧请求不会因重新开关面板或提醒设置而重放。macOS 保留原生注意力请求 ID，以便主动取消；多窗口共享 Dock 图标，关闭一个窗口的请求不会清除其他后台窗口仍需展示的状态。

提醒传输失败不阻止 ACP 授权响应，权限判断和工具执行流程保持独立。MCP 请求超时会撤回对应应用内卡片。提醒不包含 shell 命令、路径或文稿内容。

## 上下文与交互

打开面板时附加当前文档，标签可移除。`@` 检索已打开文件夹的现有文档索引，支持键盘选择；引用同时保存在用户消息中。发送时从编辑器 flush 当前正文并核对 owner 和输入状态，包含未保存正文的显式快照；移除后不把该快照重新放入请求。输入法候选期间 Enter 不发送。

输入区使用驻留的富文本编辑节点：`@` 选择的文档在正文中显示为可点击链接，不再重复显示为上方标签；删除或撤销提及同步撤销相应上下文。当前文档的自动上下文位于输入框外部上方，与输入框左侧对齐并保留 8px 间距，仍可独立移除。React 状态更新不会在输入和 IME 期间重建编辑 DOM。发送时序列化为文档链接，保留原生撤销、换行和键盘选择。

附件入口位于输入区左下角，支持选择、粘贴和拖入本地文件。上传附件在输入区顶部单行排列，超出宽度横向滚动；悬停或键盘聚焦时出现移除按钮。图片和可解码文本可打开预览；HTML/SVG 按纯文本处理，不执行脚本。每轮最多 8 个附件、总计 4 MiB，栅格图另有像素边界；不支持的能力会明确提示并保留草稿。图片通过 ACP `image` 发送，其他文件按 `embeddedContext` 使用嵌入资源；未声明该能力的智能体仅支持解码后的文本附件。声明协议能力不保证提供方能解析任意二进制格式。

发送后图片、附件和独立文档上下文位于用户文字气泡外，正文内提及不再重复生成卡片。用户消息和最终智能体回复不显示冗余身份标签，悬停或键盘聚焦时显示复制入口与时间；思考、工具、计划和过程说明不单独显示这些操作栏。正在处理时发送按钮变为停止；停止期间不可重复取消，准备阶段取消不会继续发送，未被接纳的草稿保留。查看历史列表并返回保留当前草稿，实际切换会话才重置。

图片预览使用单独的查看层：接近窗口大小、四周 8px 留白，保留唯一关闭入口；图片及查看层不附加卡片阴影。右上角提供实际缩放百分比、打开副本和系统保存，底部提供紧凑的标注、评论、调整大小与撤销。支持等比适配、放大后的拖动/方向键平移、Home 适配，以及不在文本输入内时的 Cmd/Ctrl+Z 撤销。尺寸默认锁定比例，单边/总像素有边界。

编辑只修改临时预览副本；标注和评论与导出共用绘制逻辑，缩放预览和最终图片保持一致。修改后导出为 PNG，原始聊天附件和本地源文件保持不变；未提交评论/尺寸须先应用，取消保存后保留编辑，关闭未导出修改需要确认。表单收起、撤销和确认窗口的焦点保持在图片查看范围内，避免文档快捷键误触。SVG 工具图标来自固定版本 Tabler，保留上游及打包摘要和 MIT 许可。

系统导出命令只接受经内容/MIME 验证的栅格图片，最多 16 MiB，禁止任意路径和可执行类型。保存由原生文件对话框授权目标，复用带目录句柄和变更校验的原子导出。打开外部应用使用私有临时副本，最多保留 8 份，正常关闭窗口/应用或淘汰副本时通过目录句柄清理；不改变聊天原始附件。此处没有增加 AI 去背景、智能擦除或图像生成调用。

每轮实际收到的思考、计划和工具事件归入处理过程；工具之前的说明与过程一起展示，最终回答和状态告知保持独立。运行时过程展开，工具输出仍默认折叠，由用户自行展开，后续输出更新保留手动选择。完成后过程自动折叠为带耗时的细线摘要；可再次展开，历史重开默认折叠。耗时来自本轮开始及结束时间并写入本地历史，旧记录没有时间时只显示“处理过程”。网络搜索、MCP、Skill 等仅展示智能体实际通过 ACP 报告的事件，不推测未上报的内部步骤；待批准操作不随过程折叠。

附件只在发送接纳时保存副本，本地历史仅保存 ID、名称、类型、大小和摘要。宿主校验窗口、工作区、会话归属和文件摘要，拒绝路径穿越、目录符号链接和伪造附件引用。预览按需读取，内存缓存有界；彻底删除会话一并移除本地附件副本。原文件不会因移除草稿附件或删除会话而改变。macOS 原生粘贴与拖放复用现有输入凭据和文件身份校验；其他平台的原生文件剪贴板能力尚未设备验收。

未打开文件夹时使用 MarkLyra 专属 `ai-drafts` 工作区，保留当前编辑器正文作为阅读上下文。新建内容存入 AI 草稿；界面提供打开工作文件夹的入口。对独立打开的已命名文件，宿主另提供当前文档单文件能力，可经批准修改原文件，不开放其父目录或相邻文件。

Markdown 链接和文档引用通过已授权工作区打开，拒绝父目录、私有路径、非法协议及工作区外的 file URL。HTTP(S) 链接走现有原生外链验证器，回复不执行 HTML。消息历史分批展示，代码块和工具详情有独立滚动区域。流式输出只有在用户靠近底部时自动跟随。

聊天内容使用共享的有界 Markdown 解析器。下划线强调按 [CommonMark 词内边界规则](https://spec.commonmark.org/0.31.2/#emphasis-and-strong-emphasis) 判断，`Z_AI_API_KEY` 等标识符中的下划线原样展示；独立 `_AI_` 仍作为斜体，代码与文档链接标签保持原文。处理 Unicode 标点与完整码点，同时保留 UTF-16 源坐标；未闭合下划线的后缀搜索复用结果，避免长标识符列表反复扫描。此处只修正下划线边界，不扩展有界解析器的整体语法范围。

## 会话 Harness

同一连接只允许一个会话和一个活动 prompt。每轮绑定独立 turn ID，MCP 工具只能在该轮活动期间执行。工作区、连接、原生会话归属与窗口身份分别检查，工作区被移动、关闭或替换后拒绝旧能力。恢复会话需要本地归属记录与智能体 `loadSession` 能力；不支持恢复时保留可读历史并要求新会话，不静默重放旧任务。

取消先发送 `session/cancel`，同时撤销待决权限与宿主终端；智能体未及时停止时断开并回收进程。断线后保留实际收到的内容，明确提示结果未确认，不自动重发可能已产生文件副作用的请求。历史采用原子写入与时间版本检查，手动标题不会被延迟流式快照覆盖；归档只读，可恢复；永久删除使用最小墓碑防止延迟保存复活记录。永久删除移除 MarkLyra 的本地会话内容与归属记录，智能体自身保存的历史由其管理。

历史列表以单行展示标题与图标操作，标题和元信息分别省略，完整标题可悬停查看。会话/归档均可勾选，全选覆盖当前搜索结果；搜索或切换标签清空勾选，避免隐藏项被误操作。大量结果每次展示 80 条，勾选范围仍为当前筛选的全部结果。归档页另有“清空归档”，确认弹窗明确说明其覆盖当前工作区的全部归档，不受搜索筛选影响，并展示数量和标题摘要。

普通会话批量删除复用宿主保护：先归档再彻底删除；已归档记录直接删除。删除前确认范围，处理时展示进度并锁定交互，当前运行中的会话须先停止；逐项处理，部分失败保留失败对象及最新归档状态，可重试。已成功删除的项不重复提交；若归档成功但删除失败，该记录留在归档中。现有本地附件清理、原文件保留、归属校验及墓碑机制继续生效。历史读取不再截断最近 1000 条；目录扫描超过 10000 项时明确失败，避免对不完整结果执行“清空”。

设计取舍来自以下实现的具体边界，而非引入其完整框架：

- [Codex 执行策略](https://github.com/openai/codex/blob/main/codex-rs/core/src/exec_policy.rs)：权限规则、运行权限和批准决定分开处理。MarkLyra 不建立通用 shell 前缀白名单，宿主命令请求逐次展示。
- [DeepSeek Harness 架构](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/architecture.md)：持久会话事实与活动 agent 状态分离。MarkLyra 将持久历史和进程/待决授权生命周期分开，而不另起一套模型推理循环。
- [OpenCode 会话设计](https://github.com/anomalyco/opencode/blob/dev/specs/v2/session.md)：运行归属与工作目录相关的服务边界。MarkLyra 对恢复会话加连接租约，防止不同窗口同时接管同一原生会话。
- [ZCode](https://github.com/zai-org/ZCode)：参考其作为完整 coding harness 的定位；保留外部智能体自己的模型与工具编排，应用只管理协议、编辑器上下文与文档操作。

## 文档工具与批准

内置 MCP 服务名为 `marklyra_documents`，提供当前文档单文件读取/写入、工作区文档列表/读取/写入、新建目录、移入恢复目录和恢复操作，不包含画图工具。已有文件必须先读取，写入复用 DocumentService 的保存前比较，保留原编码、BOM 和传入文本的换行。它不会把模型错误生成的整篇换行自动解释为局部修改；模型仍应遵守最小改动指令，用户可在操作卡片查看写入内容。局部修改优先使用 `editor_edit_document` / `workspace_edit_document`：要求唯一的原文片段，程序仅替换这一片段，歧义、缺失或磁盘版本变化时拒绝执行。

写入、目录变更和宿主终端运行均展示本次操作批准。批准前 flush 编辑器并检查是否存在未保存修改或 IME 候选；不静默保存或覆盖用户草稿。宿主终端的 cwd 受工作区约束，但任意系统命令本身不构成目录沙箱，因此界面直接展示命令供用户判断。

删除进入工作区 `.marklyra-ai-trash`，不永久删除用户文稿；工具返回恢复凭证，当前会话可恢复，目标存在时拒绝覆盖。进程结束后原内容仍在恢复目录内。应用私有元数据和符号链接不向文档工具开放。MCP 通过临时 loopback 桥与随机令牌绑定连接，拒绝其他窗口的回应；bridge 与子进程随连接退出。

## 发送前配置

侧栏顶部的「新建会话」菜单列出已安装智能体，停用项不可选择，底部保留管理入口。打开菜单不修改当前会话或草稿；选择已启用智能体后创建与其绑定的新会话，当前会话以只读名称与图标标明所属智能体，不再使用独立的智能体选择器。菜单支持键盘导航、Escape、点击外部关闭和焦点恢复。新建按钮使用通用 AI 图标和细边框，箭头区域以短竖线分隔；菜单与按钮等宽、左右对齐向下展开，收紧行距并使用轻阴影，管理入口采用加号图标。

新会话先执行 ACP 初始化与 `session/new`（已有历史使用 `session/load`）。按返回的 `configOptions` 顺序展示模型、思考深度、权限模式等选项；缺少配置选项时兼容 `modes`。不填充智能体未声明的选项，配置更新以服务端响应为准。依据 [ACP Session Config Options](https://agentclientprotocol.com/protocol/v1/session-config-options)，存在配置选项时不重复展示旧模式选择器。

连接期间可以编辑草稿，也可以通过新建菜单改选其他智能体；旧连接的延迟返回会被丢弃并释放。需要认证时提前展示登录入口，失败后可显式重连，不因渲染或面板收展循环重试。初始化不会发送 `session/prompt`、正文快照或 `agent_context`，空会话也不写入 MarkLyra 历史。尚未发送的会话在不支持历史恢复的智能体上可重新创建。输入区上方不再绘制分隔线。输入框聚焦仅轻微加深中性色边线，移除蓝色外轮廓与光晕；底部不再显示静态写入确认提示。配置栏隐藏可见字段标签，保留无障碍名称和悬停说明；按当前选中值的文字宽度加统一箭头留白自适应，无固定单项宽度上限，空间不足时才换行或省略，避免被未选长选项及原生箭头额外占位撑宽/裁切。

## 智能体管理

名单与 Markune 一致：Claude Agent、CodeBuddy Code、Codex、Cursor、GitHub Copilot、GLM Agent、Grok Build、Kimi CLI、MiniMax Code、OpenCode、Qoder CLI。随仓库附带 ACP Registry 固定快照，刷新从官方 HTTPS Registry 获取新目录并仍限定这 11 个身份。安装只接受固定版本与对应 npm 包身份、受信下载源，检查重定向和压缩路径；存在发行方 SHA-256 时核对，缺少发行方哈希的安装记录只证明收到的包摘要，不冒充独立发行签名验证。

受管 Node/npm、安装目录、配置和会话位于 MarkLyra 自己的数据空间。npm 使用隔离配置；下载与安装优先读取环境代理和 macOS/Windows 系统代理，不扫描端口、不关闭证书验证。安装后先在隔离 home 中验证 ACP v1 初始化，再登记可用配置。失败不替换既有安装。使用本机版本只登记程序；移除登记不会删除外部 CLI。停用会结束相应活动连接。

智能体登录方式来自 `authMethods`。标准认证直接通过 ACP；terminal 认证使用限定到已声明方法的 PTY，在侧栏中展示。没有通用的前端 shell 执行入口。显式 API 凭据写入系统凭据存储，不写入 JSON 设置、历史或日志；凭据名称按原样传入 ACP 与登录 PTY 的进程环境；更新或删除成功后撤销此配置的现有连接，下一次连接读取新值。凭据引用由宿主管理，配置保存不能用旧快照复活或清空引用。元数据提交失败时恢复原凭据及配置状态，包含写入完成后报错的情况；卸载先处理凭据，失败时保留可重试的配置，并明确报告恢复未确认的情况。删除范围是 MarkLyra 保存的系统凭据、配置引用及其控制的连接，不替服务商撤销密钥或清理外部智能体自己的登录配置。
