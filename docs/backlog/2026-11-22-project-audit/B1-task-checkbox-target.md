# B1 任务描述勾选写到别的条目

**P1 · Bug** · [返回任务索引](README.md)

## 复现

1. 打开任务描述，包含两条未勾选的 Markdown 清单项「校对格式」和「备份文件」。
2. 在点击「校对格式」与保存前读取最新版描述之间，让另一处编辑在顶部插入未勾选的「发布页面」。巡检用宿主测试数据控制了这个时序。
3. 保存请求提交了 `- [x] 发布页面`，原来点击的「校对格式」仍是未勾选。

当前实现读取最新版本后，仍用点击时的字符偏移定位复选框。新插入条目刚好占据旧位置时，会通过字符检查并写入最新版本。[任务详情](../../../apps/desktop/src/features/tasks/TaskPage.tsx#L176) · [字符替换](../../../apps/desktop/src/features/tasks/model/markdown-input.ts#L189)

## 验收

- 原描述未变化时，仅翻转被点选条目的勾选字符，保持其他正文不变。
- 在复现时序下，只能更新经过确认的原条目。无法确认时，保留最新正文并提示刷新后重试。
- 回归用例断言最终传给保存接口的正文，确认新插入的「发布页面」未被勾选。[任务浏览器测试](../../../tests/desktop-e2e/tasks.spec.ts)
