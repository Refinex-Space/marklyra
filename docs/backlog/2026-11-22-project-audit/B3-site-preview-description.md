# B3 添加站点时把旧描述保存给新网址

**P2 · Bug** · [返回任务索引](README.md)

## 复现

1. 打开「添加站点」，输入 A 的网址，等表单自动填入名称和描述。
2. 把网址换成 B。B 的预览成功返回名称，描述为空。
3. 表单显示 B 的名称，却保留 A 的描述。点击添加后，请求把 A 的描述连同 B 的网址一起保存。

预览回填只在新描述有内容时才更新描述字段。Rust 宿主会把缺失的描述以空字符串返回。[预览回填与提交](../../../apps/desktop/src/features/sites/dialogs.tsx#L93) · [宿主预览响应](../../../apps/desktop/src-tauri/src/sites/mod.rs#L597)

## 验收

- 网址从 A 改到 B 后，B 无描述、预览失败或仍在等待时，表单和保存请求均不带 A 的自动描述。
- A 的迟到响应不会覆盖 B 的预览或字段。用户手工输入的字段仍按表单既有约定保留。
- 用受控的 A、B 预览响应断言最终表单和添加请求。[站点浏览器测试](../../../tests/desktop-e2e/sites.spec.ts)
