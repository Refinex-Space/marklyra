# U5 任务清单复选框缺少可区分的名称

**P3 · 体验缺陷** · [返回任务索引](README.md)

## 现状

在同一任务描述中添加「校对格式」和「备份文件」两条未完成的 Markdown 清单项。浏览器可访问性树把两个复选框都命名为「标为完成」。条目文本与复选框是并列节点，逐个聚焦时，复选框本身的名称无法区分条目。[Markdown 清单渲染](../../../apps/desktop/src/components/MarkdownBlocks.tsx#L203)

## 验收

- 每个复选框的可访问名称包含对应清单项文本，能区分「校对格式」和「备份文件」。勾选状态由控件语义表达。
- 文本含内联格式或链接时，复选框仍有可读的名称，链接仍可独立操作。
- 在可访问性树核对名称和状态。屏幕阅读器实测结果单独记录。此任务与 [B1 勾选目标校验](B1-task-checkbox-target.md) 可分别实施。

## 验收记录

- 浏览器验证：Chromium 和 WebKit 回归通过。在 Chromium 可访问性树中，两个复选框分别命名为「校对格式」和「备份文件」。勾选前者后仅其原生勾选状态改变。独立激活链接只触发一次打开请求。首行同为「审核」的两项通过续行「项目甲」「项目乙」区分。[回归用例](../../../tests/desktop-e2e/tasks.spec.ts#L1565)
- 屏幕阅读器实测：本次未使用 VoiceOver 或 NVDA 核对实际播报。
