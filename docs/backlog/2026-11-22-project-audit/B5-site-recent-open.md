# B5 站点打开失败也计入最近打开

**P3 · Bug** · [返回任务索引](README.md)

## 复现

在站点导航点击已收藏的 Vite，让系统打开网址的调用返回失败。界面显示打开失败，但「最近打开」新增了 Vite。巡检用本地测试数据模拟了系统拒绝打开的结果。

站点打开流程在取得系统打开结果前已经开始写入历史。[站点打开流程](../../../apps/desktop/src/features/sites/SitesWorkbench.tsx#L252)

## 验收

- 系统打开请求失败时仍显示错误。失败的站点不新增到「最近打开」，已有历史也不因此重新排序。
- 系统确认接收打开请求后，站点按正常规则进入「最近打开」。历史表示系统接收了打开请求。
- 用宿主测试数据覆盖成功和失败，核对记录调用以及实际列表。[站点浏览器测试](../../../tests/desktop-e2e/sites.spec.ts)
