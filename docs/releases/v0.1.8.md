# MarkLyra v0.1.8

本版本新增 AI 待授权提醒和应用内待处理标记，并修复侧栏搜索模式下目录栏未隐藏的问题。

## 功能与修正

- AI 等待授权或补充信息时，后台窗口在 Windows 使用任务栏短暂闪烁，在 macOS 使用信息级 Dock 跳动；提醒不会激活或置顶窗口。
- 应用内显示当前窗口的待处理数量，点击可展开对应 AI 会话并定位授权卡片；提醒到达时保留原有编辑焦点，批准与拒绝仍需用户明确操作。
- “设置 → 智能体”新增“AI 等待授权时提醒我”，默认开启且持久保存；关闭系统提醒后，应用内待处理标记仍保留。
- 原生宿主核对窗口、连接、活动任务及请求身份，同一请求去重、同批请求合并提醒；处理、取消、断连、超时和窗口关闭均有清理路径。普通 ACP 完成不额外发送撤回通知，避免提供方复用请求 ID 时晚到通知误清新请求。
- 进入侧栏搜索时隐藏目录名、Git 分支、新建及搜索按钮整行，退出后恢复；修正单行导航样式覆盖 `hidden` 状态的问题。
- 更新 AI 工具栏布局回归：按真实文档栏滚动条和 AI 面板边界验证点击、拖动及动画结束状态，覆盖亮暗主题、两种标题栏与不同窗口宽度。

## 安装与限制

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装及签名更新包。macOS 使用 ad-hoc 签名，未经 Apple 公证；Windows 未使用 Authenticode 签名，系统可能显示首次运行提示。不提供 Windows ARM64、32 位或 Linux 安装包。

系统设置可能影响任务栏闪烁和 Dock 动画的呈现，应用内待处理标记会持续显示。ACP 仍不是操作系统沙箱；第三方智能体以当前用户权限运行，提醒不会改变工具授权边界。Pandoc 导出需自行安装 Pandoc，Git 同步需本机安装 Git 2.25 或更高版本。大文稿 WebKit 布局延迟的既有限制仍存在。
