# MarkLyra v0.1.2

本版本整理 `v0.1.1` 发布后的近期更新，聚焦编辑器输入体验与加载反馈：新增斜杠命令菜单与文档字数统计，主要界面在读取期间显示骨架屏，通知区分成功与警告类型，菜单入口按操作系统区分，并修正 Windows 下 Pandoc 运行时闪现控制台窗口的问题。

## 功能

- 编辑器斜杠命令菜单：在空段落输入 `/`（或中文输入法同键位的 `、`）弹出块命令菜单，覆盖各级标题、列表、引用、表格、代码块、数学块、分隔线、链接与图片，可按名称与关键词搜索；方向键移动选择，Enter 或 Tab 插入，Escape 关闭并保留已输入文本，同一段落内继续输入不会重新弹出。菜单不夺取编辑器焦点，输入法组合期间不拦截按键。
- 文档字数统计：文档卡片右下角显示当前统计值，可在词、字符、行、阅读分钟之间切换；选择与原生菜单一致并持久化。macOS 标题栏在打开文稿时提供原生“回到首页”按钮。
- 加载骨架屏：首屏、工作区侧栏与底部、首页最近文件、快速打开、最近文件面板、设置窗口与导出设置在数据读取期间显示骨架占位，不再出现“正在加载”文字，内容到达后无布局跳动；骨架是礼貌 announcing 的状态区域，并遵循系统“减弱动态效果”设置。
- 通知类型增强：通知系统新增成功与警告类型及对应样式与停留时长；导出成功与导出警告分别以对应类型提示。
- 菜单按操作系统区分：Windows 标题栏应用图标不再作为菜单入口，设置与退出保留在“文件”与“关于”菜单中；首页状态下“开始”与应用类菜单（如主题）保持可用，仅快速打开遮盖时阻止菜单。

## 修正

- Windows：调用 Pandoc 导出及能力探测时不再闪现控制台窗口（每个会话可运行多次探测）。
- 测试稳定性：编辑器冷启动的就绪等待放宽，适配较慢的托管环境；斜杠菜单测试改用方向键定位光标，避开 macOS WebKit 中 End 键只滚动不移动光标的平台差异。

## 安装与限制

安装提示与 `v0.1.1` 相同：macOS 使用免费 ad-hoc 签名、未经公证，首次打开如被阻止可在“系统设置 → 隐私与安全性”选择“仍要打开”；Windows 安装包未使用 Authenticode，可能出现未知发布者提示。不提供 Windows ARM64、32 位及 Linux 安装包。Pandoc 导出格式仍需自行安装 Pandoc。自动检查更新默认关闭。
