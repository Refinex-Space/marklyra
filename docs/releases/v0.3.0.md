# MarkLyra v0.3.0

本版本新增工作区「站点导航」：在标题栏打开收藏网址视图，支持分组、搜索、元数据与图标抓取，数据随工作区 `.marklyra/sites/` 存放并可随 Git 同步。

## 功能与修正

- 标题栏地球图标、菜单「显示 → 站点导航」与快捷键 `⌘⌥L` / `Ctrl+Alt+L` 打开站点导航；与知识图谱、任务互斥，未打开文件夹时按钮禁用。
- 设置页新增「站点导航」分区：标题栏显示开关（默认开启）、搜索引擎（内置 Bing / Google，可自定义模板）、可选第三方图标补充来源（默认关闭）。
- 主面板为搜索框与站点卡片，左侧为分组；搜索可打开网址、用当前引擎搜关键词，或匹配已收藏站点；一律经系统默认浏览器打开。
- 添加 / 编辑站点时由宿主后台抓取标题、描述与图标；图标规范化后写入工作区（单文件 ≤ 32 KB），抓取状态与最近打开记录留在本机数据目录。
- 分组拖动排序、卡片拖到分组、粘贴网址添加并可撤销；编辑面板可重新获取或上传图标。
- 本机代理失效时抓取先代理再直连回退；删除站点时清理本机最近打开与不再使用的抓取记录。

## 兼容性与安装

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装及签名更新包。macOS 使用 ad-hoc 签名，未经 Apple 公证；Windows 未使用 Authenticode 签名，系统可能显示首次运行提示。不提供 Windows ARM64、32 位或 Linux 安装包。

站点数据存放在工作区 `.marklyra/sites/`；打开站点走既有外链协议（仅无凭据的 http/https）。第三方图标补充会把公网域名发给所选服务，内网地址不会走该回退。浏览器替身不能替代真实宿主、Windows WebView2、系统浏览器或系统代理验收。
