# MarkLyra v0.3.1

本版本改进笔记与任务之间的转换，并完善 AI 侧栏的正文、表格、代码与图表展示。

## 功能与修正

- 在笔记中选中文字后，右键选择「所选文字转为任务」或按 `⌘⌥⇧T`，可以选择已有项目、新建项目或「无项目」。确认后，原选区替换为对应任务链接。取消时保留原文，选区或文档发生变化时提示重新选择。
- 首页「今天」的任务编号向左对齐，移除未显示的状态图标占位，使其与「最近查看」的内容起始位置一致。
- AI 回复支持语义标题、有序及嵌套列表、只读任务项、引用与对齐表格。宽表在块内横向滚动，聚焦后可以用方向键浏览。
- 代码块显示语言，提供自动换行和单块复制。复制保留缩进、空行与末尾换行。JavaScript、TypeScript、Python、Shell、JSON 和 diff 支持常见标记的静态着色。
- 闭合的 `mermaid` 与 `mmd` 代码块可按需离线绘图，支持源码切换与放大预览。错误、超限或不受支持的图表显示可复制源码。
- 修复 AI 消息开头的 YAML 内容丢失、行内代码中的文件名被误转成链接，以及部分表格边界内容丢失的问题。
- 流式回复复用已完成片段；异步图表更新时，贴底阅读继续跟随，向上阅读保留位置。历史会话沿用同一展示路径。

## 安装与支持范围

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装及签名更新包。macOS 使用 ad-hoc 签名，未经 Apple 公证；Windows 未使用 Authenticode 签名，首次运行可能出现系统提示。

图表由应用附带的 Mermaid 在隔离页绘制，预览使用静态图片。大消息优先保留完整文本，并在超过展示预算时回退为纯文本；代码着色限于上述语言的常见标记。
