# MarkLyra v0.2.1

本版本修复图片 Markdown 地址和手动缩放时的显示问题，并整理编辑器引擎源码与运行资源构建流程。

## 功能与修正

- 插入、粘贴和拖入图片时，普通地址直接生成 `![描述](地址)`；仅为空格、括号等需要保护的地址保留尖括号。带标题的 HTML 图片转 Markdown 使用同一规则，已有文稿不自动改写。
- 修复手动修改图片缩放比例时，`style` 的缩放值使用中文弯引号或混合引号后图片变为普通文本的问题。容错限于图片的数值缩放样式，预览和 HTML 导出保留缩放效果；后续右键缩放、撤销和重做保持可用。
- 编辑器引擎改用可读的模块源码、具名入口和显式依赖初始化，补充循环依赖、加载顺序、工厂依赖与构建边界检查。
- 运行页和编辑器包直接收集当前工作区源码与资源，整理旧构建清单、校验脚本和随包文件检查。
- 文稿操作在检查点与原生会话跟踪后再次核对当前编辑器内容和归属；导出设置的分段选项只让当前选中项进入 Tab 顺序。

## 安装与限制

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装及签名更新包。macOS 使用 ad-hoc 签名，未经 Apple 公证；Windows 未使用 Authenticode 签名，系统可能显示首次运行提示。不提供 Windows ARM64、32 位或 Linux 安装包。

Pandoc 导出需自行安装 Pandoc，Git 同步需本机安装 Git 2.25 或更高版本。大文稿 WebKit 布局延迟的既有限制仍存在。
