# MarkLyra v0.2.2

本版本新增可切换的 3D 知识图谱视图，并调整设置页的赞助入口图标。

## 功能与修正

- 知识图谱新增 2D / 3D 切换。新视图默认使用 3D，已保存的模式优先；WebGL2 不可用或上下文丢失时回退到 2D。
- 3D 模式支持轨道旋转、惯性、Shift／中键平移、指针位置缩放、按深度拾取及面向相机平面的节点拖动。
- 新增按目录着色和默认关闭的缓慢自转，保存两种相机、视图模式与外观选项，并遵循系统减少动态效果设置。
- 3D 布局在独立 Worker 中按需加载；标签采用共享图集，静止时停止逐帧绘制。
- 赞助入口使用跟随文字颜色的 SVG 心形图标。

## 兼容性与安装

知识图谱视图文件升级到 v2，可读取已有 v1 文件，保存时写入 v2；旧版应用不能读取 v2 视图文件。视图文件保存位置、相机和显示设置，与 Markdown 文稿及关系索引分开管理。

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装及签名更新包。macOS 使用 ad-hoc 签名，未经 Apple 公证；Windows 未使用 Authenticode 签名，系统可能显示首次运行提示。不提供 Windows ARM64、32 位或 Linux 安装包。

Pandoc 导出需自行安装 Pandoc，Git 同步需本机安装 Git 2.25 或更高版本。浏览器绘制测试中的 CPU 提交耗时不代表 GPU 总耗时，不能替代真实宿主、Windows WebView2 或系统输入法验收。
