# MarkLyra v0.1.6

本版本新增文档链接跳转能力，并修复编辑器在特定结构下重做失败的问题（空行数量与表格列填充差异）。

## 功能

- 文档链接跳转：在打开的文件夹内，Ctrl/⌘+点击 Markdown 链接可直接打开指向的工作区文稿（含 CJK 与空格路径，保持原始字节不变），支持相对路径规范化（`.`／`..`）、自动链接、`#` 锚点与查询后缀拆分；`http:`、`mailto:` 等外部协议与非文档目标不在此列。链接目标解析只认当前窗口已授权的工作区，超出范围的目标给出提示而不尝试打开。

## 修正

- 编辑核心：修复重做（Redo）在“序列化器两次输出同一组块、但空行数量或表格列填充不同”时失败的问题（例如段落与空代码围栏先前紧邻、重做后被空行分隔，或表格两侧列宽对齐不同）。此前该差异触发历史检查点失配并使重做被拒绝；现在先恢复日志记录的状态，再把编辑器实际内容作为一次普通编辑应用，源文本恰好获得该布局差异且镜像保持一致。仅当行尾类型一致、且差异仅为连续空行数量或表格行内填充（含分隔行单横线写法）时启用，缩进、尾随空格与任何内容变化均不适用；附单元、边界粘贴与历史专项回归测试。

## 安装与限制

安装提示与 `v0.1.5` 相同：macOS 使用免费 ad-hoc 签名、未经公证；Windows 安装包未使用 Authenticode。不提供 Windows ARM64、32 位及 Linux 安装包。Pandoc 导出仍需自行安装 Pandoc；Git 同步需要本机安装 `git` 2.25 或更高版本。

- 本地前端单元测试 1719 项通过（含链接目标解析与空行／表格填充重做单测）；类型检查、依赖边界、资源来源、发布脚本与偏好设置脚本检查通过。

- 编辑器运行时浏览器套件全量回归 2137 项通过、1 项按条件跳过（含新增空行与表格填充历史专项用例）；桌面前端构建通过。
