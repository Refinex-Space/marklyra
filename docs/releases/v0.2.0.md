# MarkLyra v0.2.0

本版本完成编辑器与设置页源码模块化整理，并修正标题栏侧边栏与大纲图标的显示。

## 功能与修正

- 标题栏采用统一尺寸的 SVG 图标，大纲按钮使用目录图标；侧边栏按钮随展开与收起状态切换图标，macOS 原生标题栏同步反映侧栏状态。
- 编辑器与设置页按职责拆分模块，通过显式清单按原有顺序组装；保留经典脚本加载地址、模块标识与既有协议，构建校验覆盖各模块、清单和最终输出。
- Emoji 关键词数据改为独立 JSON 输入，保留现有全局接口及建议项顺序，并加入数据与加载回归。
- 整理编辑器本地样式、简体中文和英文语言数据及启动错误上报代码，保留样式优先级、语言键与占位符，以及先于宿主脚本捕获启动错误的顺序。

## 安装与限制

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装及签名更新包。macOS 使用 ad-hoc 签名，未经 Apple 公证；Windows 未使用 Authenticode 签名，系统可能显示首次运行提示。不提供 Windows ARM64、32 位或 Linux 安装包。

Pandoc 导出需自行安装 Pandoc，Git 同步需本机安装 Git 2.25 或更高版本。大文稿 WebKit 布局延迟的既有限制仍存在。
