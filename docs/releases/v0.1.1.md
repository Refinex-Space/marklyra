# MarkLyra v0.1.1

MarkLyra 首个正式发布候选，提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包。`v0.1.0` 构建未通过且未发布；本版本包含跨平台验证中发现问题的修正，不复用原标签。

## 功能

- Markdown 可视化编辑与源码模式、工作区文件树与搜索、图片与表格编辑、亮暗主题和导出。
- 普通编辑与源码模式保持相同的页面背景及内容宽度。
- 设置中的手动检查更新与自动检查开关；自动检查默认关闭，下载和安装由用户决定。
- 更新检查与下载支持环境变量及系统静态代理，网络错误时尝试直连；更新包使用独立签名校验。

## 跨平台修正

- 修正 Windows 文件选择、图片绝对路径及暂存图片文件 URL 的路径表示差异。
- 复制文件遇到同名目录时，继续生成不冲突的副本名称，不覆盖已有条目。
- Windows 文件替换与撤销通过保留句柄恢复源文件创建时间，避免 NTFS 时间戳继承破坏实体及图片绑定校验；提交后的元数据失败按不确定状态处理。
- 为 Windows 原生测试配置通用控件 v6 清单；发布验证使用明确的跨平台文件系统断言。

## 安装与限制

macOS 使用免费 ad-hoc 签名，未经 Apple 公证。首次打开如被系统阻止，在“系统设置 → 隐私与安全性”中选择“仍要打开”。Windows 安装包未使用 Authenticode，可能出现未知发布者提示；组织策略可能不允许手动放行。

Windows 可能拒绝移动、重命名或删除仍被文稿、工作区或操作快照持有的目录。先保存并关闭相关文稿与工作区；仍被拒绝时，可在关闭应用后通过系统文件管理器处理。应用不会为绕过限制而放宽目录权限保护。

本版本不提供 Windows ARM64、32 位及 Linux 安装包。Pandoc 导出格式需要另行安装 Pandoc。

## 验证记录

- 本地前端单元测试 1541 项通过；类型、依赖边界、资源来源、发布脚本及桌面前端构建检查通过。
- macOS Rust 回归与相关 Chromium / WebKit 设置、更新和菜单测试通过；Clippy 保留已有警告。
- Windows 完整预检 784 项通过、2 项按原配置忽略，包括文件替换／撤销和图片绑定迁移。
- 原生安装包的三平台首次安装与隔离升级验收尚未记录。自动化测试不代表实际安装、系统代理和升级重启已完成验收；草稿须完成发布手册要求的验收后才能上线。
