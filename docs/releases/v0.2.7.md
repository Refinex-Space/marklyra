# MarkLyra v0.2.7

本版本以日历视图替代原有日记入口，按日期展示到期任务，并整理首页与设置中的相关界面。

## 功能与修正

- 新增日历面板与设置：按日查看到期任务、逾期高亮，并保存显示与行为偏好。
- 首页接入今日任务摘要；任务工作台与查询可与日历日期联动。
- 移除旧的日记（Daily）入口、偏好与相关宿主／索引代码，快捷打开与偏好页改走日历能力。

## 兼容性与安装

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装及签名更新包。macOS 使用 ad-hoc 签名，未经 Apple 公证；Windows 未使用 Authenticode 签名，系统可能显示首次运行提示。不提供 Windows ARM64、32 位或 Linux 安装包。

Pandoc 导出需自行安装 Pandoc，Git 同步需本机安装 Git 2.25 或更高版本。浏览器替身不能替代真实宿主、Windows WebView2 或系统输入法验收。旧日记偏好不会迁移到日历设置。
