# MarkLyra v0.1.4

本版本新增 Git 同步能力：把 Git 作为笔记库的版本与同步层，覆盖仓库识别与初始化、分支与远程管理、提交、拉取、推送、差异与历史查看，以及冲突时的三方合并工具。交互参照 IntelliJ IDEA 的 Git 集成并按笔记场景简化。另有测试稳定性修正。

## Git 同步

- 依赖与兼容：调用本机安装的 `git`（需 2.25 或更高），不引入 libgit2；用户已有的凭据管理器、SSH 密钥、hooks 与 `.gitconfig` 照常生效。进程不经 shell，Windows 下不弹控制台窗口，写操作按仓库串行执行。
- 分支：侧栏顶部分支按钮显示当前分支、待拉取/待推送数与状态点；分支弹窗提供搜索、同步、更新、提交、推送、获取、新建分支、签出标签或修订、日志与仓库入口，最近/本地/远程分支树支持收藏；分支操作子菜单覆盖签出、变基、合并、比较、重命名、删除等。
- Git 视图（Ctrl/⌘+Shift+G）：提交（更改勾选、目录分组、提交信息模板、修改上一次提交、Ctrl+Enter 提交、Ctrl+Shift+Enter 提交并推送）、日志（虚拟滚动提交图、引用标签、过滤、右键签出/拣选/还原/重置等）、储藏（含未跟踪文件，可应用/取回/删除）、仓库（Git 版本、远程列表与连接测试、提交身份、代理检测结果）。
- 差异与合并：差异视图支持并排/统一布局、行内高亮（CJK 按字切分）、忽略空白、折叠未更改内容、F7/Shift+F7 跳转，行尾符与 BOM 变化单独提示；三方合并工具三栏展示，采用/忽略按钮与手动编辑并存，不冲突更改自动应用，写回保留原文件 BOM 与行尾符，变基时统一按“你的/他们的”展示。
- 同步机制：一次同步依次提交全部本地更改（可关闭）、按设置的合并/变基/快进方式整合远程更改、推送并自动建立上游跟踪。手动操作先保存当前文档；自动同步遇未保存文档直接跳过，不会替用户保存。触发方式含定时、打开文件夹与保存后，连续失败按倍数退避。
- 网络与凭据：代理自动依次采用 Git 配置、环境变量与系统代理，可指定自定义代理或强制直连，代理失败可自动直连重试一次；SSH 远程可选择经代理但不动已有 SSH 配置。HTTPS 访问令牌可保存在系统钥匙串，仅执行时经环境变量传入，不进入命令行参数、仓库配置或错误信息。
- 界面集成：文件树按修改/新增/未跟踪/冲突标色，含更改的文件夹带浅色标记；菜单栏新增“Git”菜单（同步 Ctrl/⌘+Shift+K）；设置新增“Git 同步”页。架构与安全边界见仓库内 [GIT-SYNC.md](https://github.com/Refinex-Space/marklyra/blob/v0.1.4/docs/GIT-SYNC.md)。

## 修正

- 测试稳定性：偏好设置两类“真实编辑器 + 偏好页”双页用例在 WebKit 下因后台标签页定时器节流需要更长时间，放宽其用例超时；断言本身不变。

## 安装与限制

安装提示与 `v0.1.3` 相同：macOS 使用免费 ad-hoc 签名、未经公证；Windows 安装包未使用 Authenticode。不提供 Windows ARM64、32 位及 Linux 安装包。Pandoc 导出仍需自行安装 Pandoc。**Git 同步需要本机安装 `git` 2.25 或更高版本**；未安装时相关功能不可用，其余编辑能力不受影响。
