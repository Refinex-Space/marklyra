# MarkLyra v0.1.9

本版本新增文件夹知识图谱，并将编辑器运行源码、主题和设置页归入项目自身的包与应用目录。

## 功能与修正

- 打开文件夹后，可通过右上角知识图谱按钮、“显示 → 知识图谱”或 `Cmd/Ctrl+Alt+G` 查看文档关系，切换局部一跳、两跳或全目录视图。
- 图谱支持 Markdown 链接、双链及 YAML 标题、别名与标签，展示入链、出链、未解析目标与歧义；支持搜索筛选、来源定位、拖动固定节点、缩放平移、视图保存及 JSON 导入导出。关系来自已保存的正文，索引保存在本机，不改写文稿。
- 图谱按需加载，关闭或隐藏后暂停相关工作；提供键盘可访问的节点与引用列表、明暗主题、窄面板布局和减少动态效果支持。
- 编辑器程序、页面、语言与随附库由 `packages/editor-runtime` 管理，主题由 `packages/editor-themes` 管理，设置页及原生图像由桌面应用管理；构建直接使用内部源码，第三方通知统一随安装包附带。
- 设置页语言选项收敛为自动、英文与简体中文；保留主题兼容、图片字段兼容和富文本剪贴板 URI 数据，并移除旧遥测初始化及远程配置入口。
- 开发运行与 debug 构建使用独立的数据和配置目录，避免与正式安装版竞争草稿存储锁；正式版继续使用原有数据目录。
- 发布工作流改用当前设置页源码回归，修正源码迁移后失效的测试路径。

## 安装与限制

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装及签名更新包。macOS 使用 ad-hoc 签名，未经 Apple 公证；Windows 未使用 Authenticode 签名，系统可能显示首次运行提示。不提供 Windows ARM64、32 位或 Linux 安装包。

知识图谱反映磁盘上最近保存的内容，不承诺完整 Obsidian 语法或插件兼容；默认最多展示 2,000 个节点，可调至 5,000 个节点，超出预算时明确提示截断。Pandoc 导出需自行安装 Pandoc，Git 同步需本机安装 Git 2.25 或更高版本。大文稿 WebKit 布局延迟的既有限制仍存在。
