# MarkLyra v0.2.5

本版本在 0.2.4 候选内容之上修复 Windows 发布构建失败，并正式提供任务指南、路径复制与 AI 斜杠命令。

`v0.2.4` 标签已推送，但 Windows 测试失败，未产生 Release；按发布手册递增为本版本，不移动旧标签。

## 功能与修正

- 任务设置新增使用指南：分章说明项目、列表、看板、查询与导入，并可由指南直接新建任务、项目或打开导入。
- 工作区条目菜单可分别复制绝对路径与相对路径；剪贴板失败视为可重试错误，并给出明确提示。
- AI 输入支持斜杠命令（如 `/marklyra-task`），候选列表选择内置技能，并随创作区一并管理。
- 修复 Windows 上 Agent 技能安装测试：内置 `SKILL.md` 统一按 LF 处理，路径比较使用平台分隔符；并令 Markdown 检出为 LF。

## 兼容性与安装

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装及签名更新包。macOS 使用 ad-hoc 签名，未经 Apple 公证；Windows 未使用 Authenticode 签名，系统可能显示首次运行提示。不提供 Windows ARM64、32 位或 Linux 安装包。

Pandoc 导出需自行安装 Pandoc，Git 同步需本机安装 Git 2.25 或更高版本。浏览器替身不能替代真实宿主、Windows WebView2 或系统输入法验收。

## 验证记录

- 沿用 0.2.4 候选的本地自动化结果：1,984 项前端单元测试、5 项发布脚本测试和 5 项设置页资源构建测试通过。
- Rust 工作区库与二进制测试串行执行：947 项通过，5 项按既有配置忽略；6 项系统回收站测试因本机无法写入 `~/.Trash` 未在本机通过。修复后 `agent_skills` 共 6 项本地通过。
- Chromium／WebKit 相关桌面 e2e 88 项通过，另有斜杠命令 2 项通过。
- 冻结依赖安装、版本一致性、原生源码语法、类型、包依赖边界、运行页与桌面前端构建在 0.2.4 候选时通过；本修复另行通过 `agent_skills` 单元测试与 Rust fmt。
- 正式发布前需完成三平台安装与升级验收。正式发布后的旧版线上升级另行记录。

发布流程与安装提示见[发布手册](https://github.com/Refinex-Space/marklyra/blob/v0.2.5/docs/releases/README.md)。
