# MarkLyra v0.3.2

本版本集中修复剪贴板、任务清单、快速打开和站点导航中的问题，并改善窄窗口与键盘操作体验。

## 功能与修正

- Windows 剪贴板使用统一的前台窗口判定，修复 WebView2 接管键盘焦点后，复制粘贴误报「剪贴板操作仅允许由当前编辑窗口发起」的问题。
- 任务描述的勾选操作核对点击时的正文。描述已被其他编辑改动时，刷新并提示重试，避免把旧位置上的勾选写到另一条任务。
- 快速打开按条目 ID 保持选中项，笔记列表延迟返回时，键盘选择和回车目标保持一致。选中项消失时可重新选择。
- 快速打开中的同名笔记会补充可区分的目录提示，悬停和键盘选中时可查看完整路径。超长路径支持 PageUp、PageDown 浏览。
- 添加站点时，切换网址立即清理旧的自动预览，迟到响应失效。新网址没有描述、请求失败或仍在等待时，保存请求保留当前网址对应的内容；手工填写的名称和描述继续保留。
- 站点在系统确认接收打开请求后进入「最近打开」。打开失败会显示错误，已有历史顺序保持稳定，重试成功后更新历史。
- 日历周视图标题与表格行共用同一个 ISO 周标识，修复周日起始和跨年时显示两个周数的问题。
- Windows 文件设置标明文档及文件夹拖入能力的限制，禁用对应选项并提示使用「文件」菜单。图片仍可拖入正文。
- 站点搜索框恢复正常的 Tab、Shift+Tab 焦点顺序。通过引擎按钮、方向键和 Enter 可为本次搜索选择引擎。
- Windows 700 px 窄窗口保留文件名、未保存标记和标题上的重命名入口。长文件名可截断，完整名称可查看，空间充足时标题仍对齐正文中心。
- 任务清单复选框的可访问名称关联本项文字与直接续行，支持内联格式和独立链接。嵌套子项分别命名，勾选状态由原生控件表达。

## 安装与支持范围

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装及签名更新包。macOS 使用 ad-hoc 签名，未经 Apple 公证；Windows 未使用 Authenticode 签名，首次运行可能出现系统提示。

Windows 的文档及文件夹原生拖入能力仍待完善。屏幕阅读器实际播报，以及真实宿主的窗口、输入法和系统升级交互需在对应平台验收。
