# MarkLyra v0.2.10

本版本统一采用 Liquid Glass 视觉体系，按系统滚动条类型绘制一致的滚动条，改进打开文件夹时的初始视图与输入法组合期间的编辑操作，并修正子任务长标题与文件操作结果提示。

`v0.2.8` 与 `v0.2.9` 标签已推送，但构建分别因 macOS 浏览器测试和 Windows 测试准备脚本失败，均未产生 Release；按发布手册递增为本版本，不移动旧标签。本版本包含这两个候选的全部内容。

## 功能与修正

- 界面材质统一为 Liquid Glass：窗格、浮层与对话框使用一致的玻璃层级，内容层保持不透明；颜色、圆角、阴影、模糊与动效统一引用 `liquid-glass.css` 的 token。设置、AI 面板、任务、Git、知识图谱、快速打开、通知、更新等界面同步调整，macOS 与 Windows 共用同一套实现。
- 开启系统「减少透明度」时，玻璃材质改为不透明、无模糊的降级样式。
- 滚动条按系统类型处理：叠加式滚动条（触控板、Windows 的 Fluent 滚动条）保持系统原样，不占宽度；常显式滚动条（macOS「始终显示」或接了鼠标）改为透明轨道上的胶囊滑块，不再在每块面板上画出系统轨道底色。中途接上或拔掉鼠标时自动切换，壳、设置页与编辑器运行页一致。
- 编辑器运行页的右键菜单、斜杠菜单与表格控件跟随新的玻璃配色方案。
- 输入法组合期间被编辑器暂缓的操作，会在组合结束后重试，不再当作普通失败报错。
- 删除到回收站或文件撤销的结果无法确认时，只提示一次原因并刷新文件树，不再一直保留「核对结果」，也不会重复执行文件操作。
- 新窗口只打开文件夹、尚未打开文稿时，直接显示首页。
- 子任务按钮在标题过长时截断并通过悬停提示显示全文，不再撑破任务页布局。

## 兼容性与安装

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装及签名更新包。macOS 使用 ad-hoc 签名，未经 Apple 公证；Windows 未使用 Authenticode 签名，系统可能显示首次运行提示。不提供 Windows ARM64、32 位或 Linux 安装包。

Pandoc 导出需自行安装 Pandoc，Git 同步需本机安装 Git 2.25 或更高版本。浏览器替身不能替代真实宿主、Windows WebView2 或系统输入法验收；玻璃模糊效果与滚动条样式在不同系统上的观感需以真实宿主为准。

## 验证记录

- 1,957 项前端单元测试、5 项发布脚本测试和 9 项设置页／运行页资源测试通过。
- Rust 工作区库与二进制测试串行执行：937 项通过，5 项按既有配置忽略。另有 6 项系统回收站／还原测试在本维护机因无法写入 `~/.Trash`（`Operation not permitted`）失败；该项为宿主 TCC／权限限制，不是本版本改动引起的失败。
- Rust fmt、Clippy 通过；Clippy 保留既有诊断，未按已修复处理。
- 编辑器运行页的输入法组合、撤销历史与 Unicode 输入共 88 项通过；输入法组合重试用例依赖 Chromium 的 CDP 输入法模拟，WebKit 下按设计跳过 2 项。
- Chromium／WebKit 的通用设置、应用更新、回收站、工作区条目动作、滚动条、任务、首页文件夹与窗格卡片共 162 项通过。浏览器使用原生 IPC 替身。
- CI 升级到 Rust 1.100.0 后，Cargo 把测试可执行文件从 `target/debug/deps` 移到各包的构建目录，Windows 测试准备脚本因此找不到它们；脚本已改为按 Cargo 报告的 `executable` 路径添加清单。本机没有 PowerShell，该脚本以本次 Windows CI 构建为准。
- 0.2.8 候选的 CI 中，macOS Chromium 读到 runner 开启的系统「减少透明度」，更新对话框正确走了不透明降级，但测试固定断言玻璃样式而失败；测试已改为跟随该媒体查询断言对应样式，0.2.9 候选的 macOS 两个平台构建均已通过。
- 冻结依赖安装、版本一致性、原生源码语法、类型、包依赖边界、运行页与桌面前端构建通过。
- 自动化检查不能替代真实宿主或系统输入法验收；正式发布前需完成三平台安装与升级验收。正式发布后的旧版线上升级另行记录。

发布流程与安装提示见[发布手册](https://github.com/Refinex-Space/marklyra/blob/v0.2.10/docs/releases/README.md)。
