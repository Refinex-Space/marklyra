# MarkLyra v0.1.3

本版本新增日常笔记（日程）能力：工作区内以固定路径管理的每日笔记，配合侧边栏日历、首页今日卡片与新日程模板；同时修正编辑核心对缩进代码围栏关闭符的处理，使围栏后的表格解析与序列化行为一致。

## 功能

- 日常笔记（日程）：日程是工作区内固定命名的 `.md` 文件，按日期一键创建与打开，编辑体验与普通文稿一致。
  - 侧边栏日历：停靠在文件列表下方（搜索时隐藏），按月浏览，标记已有日程的日期，支持今天与前后天导航，可直接新建；可在标题栏切换日历形态，收起时只显示今天。
  - 首页“今日”卡片：显示当天未完成的待办项，点击直达对应文稿行；“今天”在跨午夜或系统唤醒后自动滚动。
  - 新日程模板：设置中可配置每一天的初始内容，支持 `{{date}}`、`{{weekday}}`、`{{week}}`、`{{title}}`、`{{lunar}}` 变量并提供首行预览；未改动的模板不会保存成文件。
  - 菜单与快速打开：“文件”菜单提供打开今日日程（Ctrl/Cmd+Shift+D）、前一天与后一天日程；快速打开可检索日程条目。
  - 日程设置：可配置日程文件夹与日期命名布局、日历形态及农历显示。
- 日历按钮与设置页样式优化。

## 修正

- 编辑核心：缩进的代码围栏关闭符（如列表内深缩进的 ``` ``` ```）现在与序列化器一致，在任意缩进处结束围栏；此前此类围栏未正确关闭，其后的表格分隔符会被误判在围栏内，导致表格无法正常识别与编辑。

## 安装与限制

安装提示与 `v0.1.2` 相同：macOS 使用免费 ad-hoc 签名、未经公证；Windows 安装包未使用 Authenticode，可能出现未知发布者提示。不提供 Windows ARM64、32 位及 Linux 安装包。Pandoc 导出格式仍需自行安装 Pandoc。日程依赖已打开的工作区且 Markdown 文件类型未被禁用；Markdown 被禁用时日程不可用。
