# MarkLyra v0.2.3

本版本新增工作区内的任务与项目管理：列表与看板、项目与迭代、查询视图，以及可导入的 Markdown 任务存储。

## 功能与修正

- 新增任务工作台（`⌘⌥T`）：项目树、列表／看板、任务详情页与任务设置，覆盖在文档卡片上，编辑器保持挂载并在遮挡时 `inert`。
- 任务数据保存在工作区 `.marklyra/tasks/`，每个实体一个带 YAML frontmatter 的 Markdown 文件；派生索引在应用数据目录，可随时重建。
- 支持项目、状态、优先级、类型、标签、队列、一层子任务、阻塞／相关、评论、归档，以及可选的迭代周期。
- 查询语法与可保存视图；笔记可插入任务／项目链接，侧栏可显示当前文稿相关任务。
- 支持从清单、CSV、GitHub 与 Octarine 导入；可选安装 `marklyra` CLI，并向 Agent／MCP 暴露任务工具。
- AI 面板可提出任务变更并以可撤销方式应用。

## 兼容性与安装

任务数据使用独立命名空间，不兼容开发期旧标识。知识图谱不把任务画成文档节点；`task:`／`project:` 链接由任务宿主解析。提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装及签名更新包。macOS 使用 ad-hoc 签名，未经 Apple 公证；Windows 未使用 Authenticode 签名，系统可能显示首次运行提示。不提供 Windows ARM64、32 位或 Linux 安装包。

Pandoc 导出需自行安装 Pandoc，Git 同步需本机安装 Git 2.25 或更高版本。CLI 与 MCP 为可选能力，不影响桌面安装与更新。浏览器替身不能替代真实宿主、Windows WebView2 或系统输入法验收。
