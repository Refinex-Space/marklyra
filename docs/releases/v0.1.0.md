# MarkLyra v0.1.0

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装包。

- 设置 → 通用支持手动检查更新及持久化的自动检查开关。
- 自动检查只提示新版本；下载、安装由用户决定，安装前处理已打开文稿。
- 更新下载支持系统静态代理和环境变量代理，更新包使用独立签名校验。

macOS 使用 ad-hoc 签名，未经 Apple 公证；首次启动可能需要到“隐私与安全性”中选择“仍要打开”。Windows 安装包未使用 Authenticode，可能出现未知发布者提示。请确认下载来源；组织管理的设备可能不允许手动放行。

自动检查默认关闭。不提供 Windows ARM64、32 位及 Linux 安装包。发布前须按仓库发布手册完成平台安装与升级验收；自动化测试不能代替原生验收。
