# MarkLyra v0.1.7

本版本新增图片与 Mermaid 大图预览，重新整理文件夹导航和最近文件界面，并集中修复编辑、剪贴板、自动保存恢复及标题栏状态问题。

## 功能与交互

- 图片与 Mermaid 图表支持悬浮入口、大图预览、缩放、平移、适应窗口与宽度、旋转及 Esc 关闭，关闭后恢复编辑焦点与选区。预览适配亮暗主题和标题栏安全区域；Mermaid 点击图表展开源码的原有操作保持有效。预览变换不写入文稿或撤销历史。
- 文件夹入口集中到侧栏顶部，提供最近目录切换、关闭目录、刷新和一级侧向的视图与排序子菜单；顶部加号支持新建文档和文件夹。菜单统一对齐，支持键盘操作与窗口边缘避让。
- 最近文件列表采用紧凑的一体化行布局，移除操作位于记录内部，列表独立滚动、底部操作固定。未打开目录时，从最近文件打开文稿可同时打开其所属目录。
- 缩小三栏分隔处的视觉间距并保留拖拽区域，调整文档统计悬浮入口与滚动条之间的距离。

## 修正与性能

- 修复自动保存成功但旧副本清理中断后，启动时仍误报需要恢复的问题；有效且尚未保存的恢复副本仍保留。
- 顺序同步标题栏最新状态，隔离过期文稿回调的错误，修复设置页返回后标题栏图标重叠等状态问题。
- 代码块语言字段支持粘贴及右键剪贴板命令，保留字段选区并防止误操作代码正文。
- 加固富格式剪贴板中的代码与公式语义、失败剪切保护、混合换行文稿的拆段与纯文本粘贴，以及粘贴和相邻键入的独立撤销步骤。
- 修复过期输入法组合回调、公式预览重绘后的右键操作、延迟挂载的公式预览、源码查找残留选区及批量标题操作对字面块的处理。
- 改善长转义文本与未闭合链接的重复扫描，限定图表依赖的全局样式影响范围，并保留异步排版等待期间新产生的编辑任务。
- 已记录的受控 WebKit 测量中，在 1 MiB 混合文稿尾部粘贴 10 KiB 纯文本，三轮稳定观察窗口中位数由 7.70 秒降至 4.71 秒。该结果为特定机器上的局部改善，仍有 6.97 秒慢样本，不代表粘贴整个 1 MiB 文稿或跨平台性能保证。详情见[性能记录](https://github.com/Refinex-Space/marklyra/blob/v0.1.7/docs/EDITOR-PERFORMANCE-2026-10-24.md)。

## 安装与限制

提供 macOS Apple Silicon、macOS Intel 和 Windows x64 安装及签名更新包。macOS 使用 ad-hoc 签名、未经 Apple 公证；Windows 未使用 Authenticode 签名，系统可能显示首次运行提示。不提供 Windows ARM64、32 位或 Linux 安装包。

Pandoc 导出需自行安装 Pandoc；Git 同步需本机安装 Git 2.25 或更高版本。高节点密度大文稿在 WebKit 中仍存在可感知的布局与绘制延迟。
