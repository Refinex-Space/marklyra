# MarkLyra v0.1.5

本版本为稳定性与诊断性更新：修复 macOS 上更新安装前退出可能崩溃的问题，为应用更新增加事件级诊断日志，修正宿主页面全选时编辑器被选区颜色整体染色的显示问题，并增强编辑器历史校验错误的诊断信息。

## 功能

- 更新诊断日志：检查、下载、安装与重启各阶段事件写入应用数据目录 `updates/update.log`（毫秒时间戳与进程号，超过 256KB 轮转为 `update.log.1`，权限 0600；不包含文档内容与密钥）。更新重启状态全程跟踪，应用退出时记录重启请求是否实际到达退出事件，便于排查安装失败。

## 修正

- macOS：原生标签页的布局刷新改由专用工作线程经事件循环转发。此前刷新运行在 AppKit/KVO 回调中，会在 Tauri 仍持有窗口表时同步重入（例如更新安装前的退出过程），触发内部借用 panic 直接中止应用。
- 编辑器：焦点在编辑器外执行全选（Ctrl/⌘+A）时，宿主页面的选区不再把整个编辑器卡片染上选区颜色；编辑器框架内部文档的文本选择行为不变。
- 诊断信息：编辑器历史检查点与规范文本不一致时，错误信息补充形态描述（双方字符数、CRLF/LF/CR 行尾统计、首个差异位置），仍不包含文档内容；附单元测试。

## 安装与限制

安装提示与 `v0.1.4` 相同：macOS 使用免费 ad-hoc 签名、未经公证；Windows 安装包未使用 Authenticode。不提供 Windows ARM64、32 位及 Linux 安装包。Pandoc 导出仍需自行安装 Pandoc；Git 同步需要本机安装 `git` 2.25 或更高版本。
