# 图标字体通知

本目录只存审查元数据和通知，不存字体或Typora商业资源。FontAwesome收到的4.1.0 WOFF与官方旧版逐字节一致，收到字体内部的Adobe版权字段原样保留；字体OFL1.1由`licenses/fonts/OFL-1.1.txt`提供，实际前端供应器输出为`fontawesome-OFL.txt`。FontAwesome CSS的MIT与文档的CC BY不替代字体许可，本项目未复制其CSS作为新的公开源码。

Ionicons原目录带完整MIT文本，实际供应器始终逐SHA附带它；官方2.0.1许可相同，但官方字体与收到的字体字节不相同，转换/子集来源仍未解决。typora-icon与4份Native派生PNG没有公开再分发批准。`manifest.json`与供应器固定通知摘要，收到字体字节与内部名称均未修改；CSS别名不是内部改名。
